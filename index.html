Adding the next iteration

  1. Upload the next build to this same repository.
  2. Use a versioned filename such as Playable_Base_v0.1.2_Offline.html.
  3. Change the Latest button in this file to the new filename.
  4. Move the former latest build into Previous Iterations.
  5. Commit the changes and let GitHub Pages redeploy.

Recommended repository layout

/
├── index.html
├── Playable_Base_v0.1_Offline.html
├── Playable_Base_v0.1.1_Offline.html
└── future iterations...
All links are relative, so this works with GitHub Pages project repositories.
